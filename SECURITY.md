# Security Policy

Rorfost includes experiments, tools, and learning projects. Some projects are not ready for production, but we still welcome security reports.

## Report a security issue

Please do not open a public issue for a possible security problem. Send the details to [rajpatel7807@gmail.com](mailto:rajpatel7807@gmail.com) so we can review them first.

Include these details when you can:

- Affected repository and component
- Version, release, or commit
- Steps to reproduce the problem
- Possible impact
- A safe proof of concept, if available

Rorfost is independently maintained. We will review reports as time allows and decide on a fix or disclosure plan based on the issue and the affected project.
