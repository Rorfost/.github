# Rorfost GitHub files

This repository holds the shared GitHub files for Rorfost.

It includes the organization profile, community rules, contribution guide, issue forms, pull request template, security policy, and support guide. A project can add its own files when it needs different rules.

## Brand assets

The Rorfost logo images are in [`assets`](assets). Use the horizontal logo in wide spaces and the icon in small spaces. Keep their original shape and use a white background.
